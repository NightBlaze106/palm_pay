Biometric Processing Pipeline

Modular Architecture

The system transforms standard 2D RGB webcam frames through a multi-stage biometric pipeline without requiring specialized infrared hardware:

1. Hand & Landmark Detection

MediaPipe Hands tracks 21 3D landmarks in real time on CPU. Extracts wrist (0), index MCP (5), middle MCP (9), and pinky MCP (17).

2. Landmark-Guided Palm ROI

Calculates palm center and wrist-to-middle MCP vector. Applies affine transformation to crop a rotation-normalized 128×128 px square palm ROI.

3. CLAHE Contrast Enhancement

Converts ROI to grayscale and applies Contrast-Limited Adaptive Histogram Equalization (CLAHE) to expose epidermal creases and principal lines.

4. Feature Extraction ({{ model_name }})

Divides 128×128 ROI into a 4×4 spatial grid. Extracts 59-bin uniform LBP histograms per block ($LBP_{8,1}^{u2}$) concatenated into a 944-D unit-normalized feature vector.

5. 1:N Cosine Similarity Matching

Computes cosine similarity against enrolled templates in SQLite: $\text{Sim}(\mathbf{q}, \mathbf{t}) = \mathbf{q} \cdot \mathbf{t}$. Applies configurable threshold to verify identity.

MediaPipe Hands		 Real-time 21 3D hand landmark estimation on commodity mobile/laptop CPUs using single RGB frames. Provides hand detection and palm knuckle / wrist anchor landmark extraction.
Sánchez-Brizuela et al. (2023)
Sensors		 Landmark-based geometric normalization for contactless hand/palm biometric ROI extraction. Basis for computing orientation vector ($\vec{v}_{0 \to 9}$) and affine warping for scale/rotation invariance.
